# Regras de Governança de IA

1. O código gerado por IA deve ser revisado por uma pessoa.
2. Requisitos e regras de negócio devem estar documentados.
3. Não aceitar alterações que violem a restrição de disciplinas.
4. Toda funcionalidade nova deve possuir testes automatizados.
5. Não registrar senhas ou dados pessoais desnecessários.
6. Validar entradas antes de realizar cálculos ou operações com arquivos.
7. Não excluir ou mover arquivos sem uma ação explícita do usuário.
8. Documentar alterações importantes no projeto.
9. Executar os testes antes de considerar uma versão aprovada.
10. Não declarar o sistema homologado sem revisão e testes executados.
